# ファイルデータ移行＆システムツール<br>
## 1.アプリ概要<br>
本アプリは、初心者でもファイルデータの移行やWindowsのシステムの修復ができるようにしたアプリです。<br>

## 2.機能概要について<br>
主に機能としては、2つあります。**Windowsのシステム修復機能・ファイルデータ移行機能**です。<br>

**〇ファイルデータ移行機能**<br>
  **アカウントデータ移行 or ドライブ選択**　から選ぶことができます。

**〇Windowsのシステム修復機能**
  スタートから起動しなくても、アプリ1本で修復できるように設計。<br>
  機能としては、**回復ドライブ・システムイメージ作成・ディスクチェックコマンド・sfc/scannowコマンド・回復環境**　が使えます。
